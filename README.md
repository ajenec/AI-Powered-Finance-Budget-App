# AI-Powered-Finance-Budget-App

## Project Overview

This is a full-stack web application designed to help users take control of their personal finances by tracking income, expenses, and budgets in a secure and intuitive way. The app uses AI-powered insights to provide personalized recommendations, including recognizing spending patterns, and suggest areas for saving. While also predicting whether users are likely to meet their financial goals.

The main goal of this project is to showcase backend development knowledge, including secure user authentication, relational database design, and API integration. While also displaying AI integration for real-world problem solving.
